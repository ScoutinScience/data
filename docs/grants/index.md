# Grants

We collect open grant calls from funding bodies so that projects such as [Matchmaking]({{ "/projects/matchmaking/" | relative_url }}) and [GFS]({{ "/projects/gfs/" | relative_url }}) can pair them with the right researchers and publications. Each funder is a **data intake**: one page per source, describing how we collect its calls and where they land.

## Grant attributes

Every grant is stored in the `Grants` table with the attributes below. The **required** ones (highlighted) must be supplied by every source — a source that can't provide them isn't ready to be ingested. The rest are filled when the source has them, or generated by the platform.
